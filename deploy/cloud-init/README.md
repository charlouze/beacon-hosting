# cloud-init

Le catalogue par jeu, et le `cloud-init` que la Function pose sur l'instance au
provisionnement : le seul endroit du dépôt qui sache par quel port, quelle image
et quelle variable un jeu se lance.

Ce que le rendu contient, comment le relire au terminal et comment le valider
sans allumer de machine sont documentés dans [`../README.md`](../README.md).
